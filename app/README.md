# Expense Manager — Android app

React Native 0.88 (TypeScript), Android only.

```bash
npm install
npm start          # Metro bundler
npm run android    # build and install on a connected device or emulator
npm test
```

Source lives in `src/`: `theme/` (Midnight & Gold tokens), `components/`, `onboarding/`, `navigation/`.
Fonts (Manrope, Inter — OFL) are bundled in `android/app/src/main/assets/fonts`.
